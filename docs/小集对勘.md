## 否决的理由

疑似错字逐条复查了全部检索结果：本库读法只要在某一部古籍中原样出现，就算异文，不改。

- **有古籍原样作证**：海不厌深、念之断人肠（《选诗》《乐府诗集》）；高驰（楚辞，补注本作「驼」，一作驰）；与美人抽思、愿径逝而未得、折若椒以自处、心戃慌其、躬速速其、从玄鹤与鹪明、堇荼茂兮扶疏；斯逝不至（毛诗）、酒醴维醽；蔷薇影暗空凝贮（《通志堂集》）、早寒惊梦频（《今词初集》）。
- **异体字或古今字**：浑浊/溷浊、嵾/㠁、钜/巨、辞/词、鵔/鵕、谘/咨、骪/骫、塈/墍、旙/旛、罥/𦊰。
- **OCR 或旧刻字形**：已/巳（人已去、冬已半、知而不已）、匕/七（有捄棘匕）、诳/廷（廷 是 迋 的误识）。

## 未定
