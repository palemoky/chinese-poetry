# 繁体混入简化字

`全唐诗/poet.*`（唐诗与宋诗）是繁体录文，但夹杂着简化字，如「風带泉聲」「由来事」。这些字在繁体文本里不该出现，2026-11 统一改回繁体正字。

## 改了什么

- 范围：`全唐诗/poet.*.json` 中以繁体书写的诗，只改 `title` 与 `paragraphs`。
- 规模：146 个字，10,928 处，涉及 295 个文件；逐处记录在 [`繁体混入简化字.tsv`](繁体混入简化字.tsv)。
- 最多的是 带→帶（6,221）、来→來（1,993）、将→將（672）、随→隨（326）。

字表是 `scripts/check_structure.py` 中的 `SIMPLIFIED_IN_TRAD`。`scripts/fix_simplified.py` 按它写回，`check_structure.py` 的 `simplified_in_trad` 检查用它防止再混入（CI 中数量不得增加）。

## 判定规则

一个字进入字表，须同时满足：

1. 是《简化字总表》里的简化字（含偏旁类推简化，如 钴、鼹）。
2. 在 OpenCC 字表中简转繁只有一个结果；原字不在 Big5 内，结果在 Big5 内。

条件 2 先从 OpenCC 一对一、不在 Big5 内的字中筛出 290 个在本库出现过的候选，再按条件 1 逐字人工判定，留下 146 个。

### 不改

- **字形或异体差异**：黄/黃、却/卻、凉/涼、卧/臥、别/別、户/戶、静/靜、泪/淚、叠/疊、灾/災 等 140 个字。它们不是简化字，底本大量使用（黄 23,767 处，黃只有 4,606 处），属于原貌。
- **本身就是古字的简化字**：无、凭、尔、号。古书里可能本来就这样写（「无咎」「凭几」），列在 [`繁体混入简化字.待核.tsv`](繁体混入简化字.待核.tsv) 中逐处核对，未改。
- **繁体里本就合法的字**：峰、群、床、秘、栖。OpenCC 会转成旧字形 峯、羣、牀、祕、棲，但它们在 Big5 内，不进字表。
- **整首以简体录入的诗**：诗中 GB2312 编不了的繁体字比字表中的简化字还少时视为简体书写，跳过。与 OpenCC 的简繁判定对比过，没有繁体诗因此被跳过；只有「山僧带雪期」「思君带孔移」两句全无繁体字可依，留作原样。
- `tags`、`prologue`（合并选本时加入的简体标注）与 `author`（关系到作者匹配）。

## 效果

用 chinese-poetry-api 处理修复后的数据：繁体表中含「来」的诗 1,797 → 0，含「带」的 6,011 → 1。另有 16 首此前因简化字太多被误判为简体书写，简体表中原样保留了繁体字（如「世事違人」），现在都能正确转成简体。

## 重新运行

```bash
python3 scripts/fix_simplified.py              # 预览
python3 scripts/fix_simplified.py --apply      # 写回并更新 繁体混入简化字.tsv
python3 scripts/check_structure.py --only simplified_in_trad
```

`--apply` 写回时保持原有 JSON 格式，并校验新旧文件只在被替换的字上不同。
