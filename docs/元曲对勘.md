# 元曲对勘

把 `元曲/yuanqu.json` 中约 1.1 万首（散曲、杂剧曲文、南戏）、12.8 万句逐句与古籍比对，找出形近、音近的错字（如「鸾风和鸣」→「鸾凤和鸣」、「击一条一抹绦」→「系一条一抹绦」）。方法与 [宋词对勘](宋词对勘.md) 相同，用同一个脚本 [`scripts/collate.py`](../scripts/collate.py)。

## 判定规则

与宋词相同（详见 [宋词对勘 § 判定规则](宋词对勘.md#判定规则)）：只看一字之差；他本读法有 ≥2 种古籍支持、且本库读法在检索到的古籍中一种都没有，才列为疑似错字；两读皆有古籍、异体字、古书通用字和古今字不改。自动判定只是建议，每一处都由人确认后才写回。

**丢字**：整部元曲 85 万字中只有 123 个 GB2312 以外的字（每万字 1.4 个，宋词为 43 个），生僻字多半在导入时被丢掉或变成了乱码（《宋词三百首》就丢了 59 个，如「如三鼓」→「紞如三鼓」）。2026-11-06 起 `collate.py` 也检出这类情况：他本多出一个 GB2312 以外的字、去掉后与本库相同，且有 ≥2 种古籍支持、本库读法无古籍，审核表 evidence 列标 `dropped char`，`proposed` 为补字后的句子。

元曲审核时特别留意：

- **古今字、俗写**（的/得、每/们、着/著、恁/您、么/末……）已列入白名单，审核表里若还出现同类字对，填 `reject` 并考虑补进 `INTERCHANGEABLE`。
- **曲谱**（《九宫大成》《御定曲谱》等）常改字以合律，只有曲谱支持的读法要谨慎。
- **OCR 误识**：识典古籍的文字多为 OCR，形近字（援/摇、叶/協）要看原书页面。

## 自动检索（GitHub Actions）

workflow 每 4 小时运行一次（每次约 1～2 小时，每条检索平均约 3～6 秒）：

1. 按当前数据生成检索计划（`collate.py plan --dir 元曲`）
2. 检索识典古籍 1200 条（`search.mjs --limit 1200`，每条间隔 3～4.5 秒）
3. 判定检索已全部完成的作品（`collate.py analyze`），进度表写在运行页面的 Summary 中
4. 上传审核表 artifact `collate-yuanqu-review`（`review.tsv`、`state.json`、`plan.json`）

- 同一时间只运行一次（`concurrency`）：上一次还没结束时，下一次排队等待，不会并发访问识典古籍。
- 检索结果缓存在 Actions cache 中，逐次累积；中途失败或超时也会保存，下次自动从断点继续。cache 连续 7 天未使用会被 GitHub 清除，届时从头检索。
- 想临时多跑一些：在 Actions 页面手动运行（Run workflow），可填写本次检索条数（每次不超过 2000 条，否则可能超出 4 小时时限）。
- 已写回或否决的句子记在 [`元曲对勘.applied.json`](元曲对勘.applied.json)，随仓库提交，之后的审核表不再出现。
- 检索全部完成后，删除 `collate-yuanqu.yml`，或把 cron 改成每天一次以便写回后复查。

## 审核与写回（攒到几十处时做一次即可）

```bash
pip install opencc-python-reimplemented                      # 只需一次
W=~/.cache/chinese-poetry/yuanqu-review && rm -rf $W
gh run download --repo palemoky/chinese-poetry -n collate-yuanqu-review -D $W   # 下载最近一次运行的审核表
```

1. 打开 `$W/review.tsv`，逐行看 `original`（本库）、`proposed`（建议）和 `evidence`（支持的古籍）。
2. 逐条填写 `decision` 列（留空的行不写回，不要整列采纳）：
   - `accept`：采纳建议
   - `reject`：不改，以后不再出现
   - 直接填写正确的整句：按你的写法改
3. 写回数据、记入 `fix_progress.json` 与 `元曲对勘.applied.json`，并更新本文档的进度：

```bash
A=docs/元曲对勘.applied.json
python3 scripts/collate.py apply  --work $W --applied $A --reviewer <你的名字或 GitHub ID> --date YYYY-MM-DD
python3 scripts/collate.py report --work $W --applied $A --doc docs/元曲对勘.md --date YYYY-MM-DD
git add 元曲 fix_progress.json docs/元曲对勘.md $A && git commit -m "fix: 元曲对勘 …"
```

审核表的 key 是 `文件#记录下标#句序`。增删 `yuanqu.json` 的记录会使下标错位，对勘期间请不要增删记录（改字不受影响）。
