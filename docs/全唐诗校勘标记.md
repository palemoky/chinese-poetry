# 全唐诗校勘标记

`全唐诗/` 的补编部分（`poet.tang.50000`–`57000`，录自《全唐诗补编》等整理本）和正编部分诗篇的正文里，原样带着整理本的校勘标记，如 `閑[宵]（霄）望月`、`[爽]節在重九`、`毫（鶴）立蛇形`。读者和 API 直接拿到的是带标记的文本，检索、统计字数都会出错。

2026-11-06 起，正文（`title`、`paragraphs`）只保留校定后的读法，标记连同前后几个字原样记进该首的 `notes`，信息不丢失。

## 已处理的写法

| 写法 | 含义 | 正文改为 | 例 | 处数 |
|---|---|---|---|---:|
| `[X]（Y）` | X 为整理者校定的字，Y 为底本原字 | X | `閑[宵]（霄）望月` → 閑宵望月；`電舉[朝]（潮）宗外` → 朝宗 | 319 |
| `[X]` | 整理者补的字 | X | `[爽]節在重九` → 爽節；`應[制]` → 應制 | 764 |
| `[X]□…`（□ 个数与 X 字数相同） | 为缺字框补出的字 | X | `有時[遇豐年]□□□` → 有時遇豐年 | 13 |
| `X（Y）`（仅 `poet.tang.50000` 敦煌写本部分） | X 为写本原字，Y 为正字 | Y | `毫（鶴）立` → 鶴立；`肝腹（腸）一斷` → 肝腸 | 130 |
| `[一]`、`〖1〗` | 整理本脚注编号（脚注本身未收录） | 删除 | `寧知猗（椅）[一]` | 767 |

共 58 个文件、1324 首；`notes` 中新增 1213 条，形如 `閑[宵]（霄）`、`有時[遇豐年]□□□`、`題：宴百僚應[制]`（`題：` 表示出自标题）。

## 未处理的写法

- **其他文件中的 `X（Y）`**：括号的用法不统一，有「（句）」（残句）、「（疑）」（存疑）、「（題擬）」（拟题）、「（幷序）」，也有补字、异文，不能一律当作正字，保留原样。
- **`〖…〗`**：全部出现在（…）注文之中（校记里的小注，如 `蔣禮鴻〖簡稱「蔣」〗`），不在诗句里，保留原样。
- `[□□]`、`□[X]` 等与缺字框相邻但字数不合的少数写法。

批量处理脚本的规则写在 `fix_progress.json` 各文件的 `[markup]` 条目中。
